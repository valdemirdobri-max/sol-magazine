# Mapa de Arquivos e Seções — Site Institucional Sol Magazine 2026

> Versão congelada: **HTML Navegável Pré-Conteúdo V1**. Mapeamento de todos os arquivos do site e das seções existentes em cada página, para orientar a entrada de conteúdo real.

## Estrutura geral

| Arquivo | Tipo | Função |
|---|---|---|
| `index.html` | Página | Home |
| `quem-somos.html` | Página | Institucional |
| `presenca-nacional.html` | Página | Institucional |
| `imoveis.html` | Página | Captação (formulário) |
| `fornecedores.html` | Página | Captação (formulário) |
| `expansao.html` | Página | Institucional / captação |
| `trabalhe-conosco.html` | Página | Captação (formulário) |
| `contato.html` | Página | Contato (formulário + canais) |
| `styles.css` | Estilo | Folha de estilo única, compartilhada por todas as páginas |
| `script.js` | Script | Comportamento compartilhado (menu mobile, dropdown, simulação de envio de formulário) |

Todas as 8 páginas compartilham o mesmo `<header class="site-header">` (logo, navegação, dropdown "Oportunidades", CTA "Fale Conosco") e o mesmo `<footer class="site-footer">` (barra de credibilidade, colunas Institucional/Oportunidades/Contato, rodapé legal).
